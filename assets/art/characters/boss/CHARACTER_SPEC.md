# 박태식 캐릭터 명세

- 캐릭터 ID: `boss`
- 이름: 박태식
- 역할: 게임사업실 부장
- 연령대: 40대 후반~50대 초반의 한국인 남성
- 얼굴: 넓고 각진 얼굴형, 짙고 곧은 눈썹, 눈가와 이마의 옅은 주름, 엄격한 인상
- 눈: 짙은 갈색, 정면을 응시하는 날카로운 눈매
- 헤어: 이마가 드러나는 짧은 검은 머리, 양옆으로 단정하게 넘긴 형태
- 체형: 키가 크고 어깨와 허리가 넓은 묵직한 중년 체형
- 기본 의상: 소매를 걷은 흰색 셔츠, 느슨한 검은 넥타이, 검은 슬랙스와 구두
- 고정 액세서리: 짙은 사원증 목걸이와 빈 사원증
- 시각적 성격: 엄격하고 피곤해 보이지만 현장 상황을 빠르게 정리하는 관리자
- 현재 승인 포즈: 종이컵을 든 정면 전신
- 현재 승인 표정: 미간을 찌푸린 걱정·압박 표정

기존 `NAN_GAME_TITLE/assets/characters/boss-standing.png`를 마스터 참조로 사용한다. 얼굴, 체형, 헤어, 의상과 사원증을 임의로 변경하지 않는다.
