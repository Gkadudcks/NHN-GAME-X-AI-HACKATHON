# DAY 2 부장님 몰래 메신저하기 · 경고 UI 수정 계획

## 상태

- 문서 상태: 구현 결정 완료
- 코드 상태: 미착수
- 선행 문서: [개선 추적 문서](./IMPROVEMENT_TRACKER.md)

## 목표

화면이 `주의`, `위험`, `곧 뒤돌아봅니다`라고 정답을 알려주는 구조를 제거한다. 플레이어는 박태식 부장의 자세, 몸짓, 말풍선과 회전 동작을 보고 입력을 계속할지 멈출지 판단한다.

이번 수정은 경고 전달 방식만 바꾼다. 누르고 있는 동안 답장이 작성되는 현재 조작, 메시지 세 개, 제한 시간, 경고 3회 실패, 결과 등급과 호감도 보상은 유지한다.

## 현재 문제

- 상단 상태 UI가 `서류 확인 중 · 안전`, `커피를 내려놓았다 · 주의`, `도윤 쪽을 보는 중 · 멈춤`으로 현재 상태와 정답 행동을 직접 노출한다.
- 노란 경고 배너가 `잠시 후 부장님이 뒤돌아봅니다`라고 다음 상태를 미리 알려준다.
- 경고 효과음이 행동 관찰보다 먼저 위험을 알려준다.
- 부장 캐릭터는 뒷모습과 정면 두 포즈만 사용해 전조 행동과 훼이크를 표현하지 못한다.
- 고정 7초 주기가 반복되어 몇 번 플레이하면 화면을 보지 않고도 타이밍을 외울 수 있다.

## 변경 범위

### 제거할 직접 경고

- 플레이 화면의 `.sc-watch.sc-patrol` 상태 패널을 제거한다.
- `.sc-scene-warning` 노란 경고 배너를 제거한다.
- `phaseCopy()`와 `#sc-status`, `#sc-meter` 참조를 제거한다.
- 전조 시작 시 호출되는 `playMinigameCue("warning")`를 제거한다.
- CSS의 `warning`·`danger` 상태별 패널 색상 변화와 경고 배너 규칙을 제거한다.

누적 실수 횟수인 `경고 0/3`, 발각 직후의 `발각!`, 전송 성공 피드백은 결과 정보이므로 유지한다. 이 요소들은 미래 위험을 알려주지 않는다.

### 추가할 부장 행동

부장 요소 `#sc-office-boss`에 `data-behavior`를 적용한다.

| 값 | 화면 행동 | 위험 판정 |
| --- | --- | --- |
| `work` | 등을 보인 채 서류나 모니터를 확인한다. | 안전 |
| `scratch` | 고개를 기울이고 한 손으로 머리를 긁는다. | 전조 또는 훼이크 |
| `throat-clear` | 어깨를 들썩이며 `크흠` 말풍선을 표시한다. | 전조 |
| `stretch` | 양팔을 올리고 길게 기지개를 켠다. | 훼이크, 안전 |
| `turn` | 의자와 상체가 도윤 쪽으로 단계적으로 회전한다. | 반응 유예, 안전 |
| `watch` | 정면을 보고 도윤의 자리를 감시한다. | 입력 시 발각 |
| `recover` | 정면에서 뒷모습으로 돌아간다. | 안전 |

`scratch`, `throat-clear`, `stretch`는 기존 부장의 얼굴·헤어·체형·의상과 팔레트를 그대로 재조합한 포즈로 만든다. 새 이미지 에셋은 추가하지 않고 분리된 외부 픽셀 SVG를 재사용한다.

### 행동 패턴

행동은 패턴 단위로 실행한다. 첫 실제 감시는 학습 가능하도록 고정하고, 이후에는 네 패턴을 중복 없이 섞은 뒤 다시 섞는다.

| 패턴 | 상태 순서 | 용도 |
| --- | --- | --- |
| 실제 감시 A | `work → throat-clear → turn → watch → recover` | 소리와 상체 회전으로 강한 예고 |
| 실제 감시 B | `work → scratch → turn → watch → recover` | 약한 행동 뒤 확정 회전 |
| 훼이크 A | `work → stretch → recover` | 길게 입력할 수 있는 명확한 훼이크 |
| 훼이크 B | `work → scratch → recover` | 같은 머리 긁기 행동이 항상 감시로 이어지지 않게 함 |

첫 패턴은 `실제 감시 A`, 두 번째 패턴은 `훼이크 A`로 고정한다. 플레이어는 실제 감시와 훼이크를 초반에 모두 경험한다. 세 번째부터 패턴 묶음을 섞는다.

### 시간 규칙

| 상태 | 지속 시간 |
| --- | --- |
| 첫 `work` | 3,800ms |
| 이후 `work` | 2,600~4,200ms |
| `throat-clear` | 900ms |
| `scratch` | 1,000ms |
| `stretch` | 1,400ms |
| `turn` | 750ms |
| `watch` | 1,600ms |
| `recover` | 550ms |

실제 감시에는 항상 750ms의 `turn` 상태가 선행한다. `scratch`처럼 애매한 전조가 실제 감시인지 훼이크인지 구분되지 않더라도, 발각 판정 전에 확정 회전 동작을 보고 손을 뗄 시간이 보장된다.

`work` 시간만 범위 안에서 무작위로 정한다. 전조·회전·감시 시간은 첫 구현에서 고정해 플레이테스트 시 원인을 분리한다.

## 상태와 데이터 흐름

- 기존 시간 나머지 기반 `phaseAt(ms)`를 행동 패턴 큐 기반 진행으로 교체한다.
- 상태에는 현재 행동, 행동 시작 시각, 종료 시각, 남은 패턴 큐를 저장한다.
- 순수 함수로 행동 패턴 순서와 다음 상태를 계산해 자동 테스트에서 고정 난수 함수를 주입할 수 있게 한다.
- 렌더 함수는 현재 행동을 `data-behavior`에 반영하고, `throat-clear`일 때만 `크흠` 말풍선을 표시한다.
- 발각 판정은 현재 행동이 `watch`이고 `state.typing`이 참일 때만 실행한다.
- 전조 행동 중에는 현재 자동 작성 속도를 바꾸지 않는다. 난이도와 타이핑 속도는 후속 작업에서 별도로 조정한다.
- 한 번의 `watch` 구간에서는 경고를 최대 한 번만 부여한다.
- 일시정지와 재개 시 행동 종료 시각도 정지 시간만큼 이동해 패턴이 건너뛰지 않게 한다.

## 시각·접근성 규칙

- `크흠`은 말풍선으로만 표시하고 `주의`, 느낌표, 경고색 테두리를 사용하지 않는다.
- `turn`은 최소 두 단계의 계단식 회전 포즈로 표현한다.
- `stretch`는 팔을 머리 위로 올려 다른 행동과 실루엣만으로 구분되게 한다.
- `scratch` 훼이크와 실제 감시는 첫 동작이 같아도, 실제 감시에만 `turn` 포즈가 이어진다.
- 화면 읽기 도구용 비가시 `aria-live` 영역에는 `부장이 머리를 긁습니다`, `부장이 몸을 돌립니다`, `부장이 도윤 쪽을 봅니다`처럼 실제 행동만 설명한다. 정답 행동은 안내하지 않는다.
- 모션 감소 설정에서는 이동 애니메이션을 제거하되 각 행동의 고정 포즈와 말풍선은 유지한다.
- 부장 행동 외의 캐릭터 배치, 크기, 배경, 타이포그래피는 이번 작업에서 변경하지 않는다.

## 테스트 계획

### 자동 테스트

- 렌더링 소스에 `잠시 후 부장님이 뒤돌아봅니다`와 `.sc-scene-warning`이 남아 있지 않다.
- 상단 상태 패널과 `phaseCopy()`가 제거되어 있다.
- 실제 감시 패턴 두 개는 모두 `turn`과 `watch`를 포함한다.
- 훼이크 패턴 두 개는 `watch`를 포함하지 않는다.
- 모든 실제 감시는 최소 750ms의 `turn` 이후 시작된다.
- 첫 두 패턴은 실제 감시 A와 훼이크 A 순서다.
- 패턴 묶음에는 실제 감시와 훼이크가 각각 두 개씩 존재한다.
- `watch` 중 입력할 때만 경고가 증가하고 한 감시 구간에서 중복 증가하지 않는다.
- 경고 3회 실패와 완료 결과 객체의 기존 필드가 유지된다.
- 일시정지·재개 후 현재 행동의 남은 시간이 보존된다.

### 독립 Lab 플레이테스트

- 1280×720, 1440×900, 1920×1080에서 직접 경고 문구와 상태 패널이 보이지 않는다.
- 첫 20초 안에 실제 감시와 스트레칭 훼이크를 각각 한 번 경험한다.
- `크흠`, 머리 긁기, 스트레칭을 별도 설명 없이 시각적으로 구분할 수 있다.
- 실제 감시에서는 상체 회전을 본 뒤 버튼을 놓아 발각을 피할 수 있다.
- 스트레칭 중 계속 입력해도 발각되지 않는다.
- 머리 긁기 훼이크 뒤에는 정면 감시 포즈가 나타나지 않는다.
- 감시 중 계속 입력하면 경고가 정확히 한 번 증가한다.
- 일시정지 후 재개해도 부장 행동이 즉시 건너뛰거나 중복 실행되지 않는다.
- 콘솔 오류와 경고가 없다.

## 완료 조건

- 직접 경고 UI와 직접 경고 효과음이 제거된다.
- 실제 감시 두 종류와 훼이크 두 종류가 동작한다.
- 플레이어가 부장의 확정 회전 동작에 반응할 시간이 보장된다.
- 기존 조작, 제한 시간, 결과·보상 계약과 본편 진행에 회귀가 없다.
- 자동 테스트와 세 PC 해상도 독립 Lab 플레이테스트를 통과한다.
- 완료 후 [개선 추적 문서](./IMPROVEMENT_TRACKER.md)의 경고 UI 항목을 `완료`로 갱신한다.
