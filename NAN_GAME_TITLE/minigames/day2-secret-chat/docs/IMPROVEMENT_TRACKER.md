# DAY 2 부장님 몰래 메신저하기 · 개선 추적 문서

## 문서 목적

이 문서는 DAY 2 미니게임 `부장님 몰래 서하린에게 답장하기`에서 확인된 문제와 수정 방향을 한곳에서 추적한다. 각 항목은 한 번에 묶어서 수정하지 않고, 독립 작업 단위로 계획·구현·플레이테스트한다.

적용 대상은 다음과 같다.

- 본편 진입점: `NAN_GAME_TITLE/day2.html`
- 공개 진입점: `NAN_GAME_TITLE/minigames/day2-secret-chat/index.js`
- 전용 스타일: `NAN_GAME_TITLE/minigames/day2-secret-chat/style.css`
- 독립 Lab: `NAN_GAME_TITLE/minigames/day2-secret-chat/dev/index.html`
- 관련 테스트: `NAN_GAME_TITLE/minigames/day2-secret-chat/tests/index.test.js`

DAY 2 스토리, 진행 저장, 호감도 보상 계약은 개별 작업에서 명시적으로 포함하지 않는 한 변경하지 않는다.

## 목표 경험

플레이어는 도윤의 자리에서 실제로 메시지를 작성하면서, 화면 위쪽에 있는 박태식 부장의 몸짓을 곁눈질한다. 직접적인 경고 문구가 아니라 부장의 행동을 읽고 입력을 계속할지 멈출지 판단해야 한다. 화면은 회사 잠입 시트콤처럼 보여야 하며, 조작 대상인 도윤과 감시 대상인 부장이 가장 먼저 읽혀야 한다.

## 작업 순서

1. 도윤 중심의 화면 배치, 책상·파티션 구조와 배경 사용 기준을 확정한다.
2. 캐릭터 표시 크기, 입력 영역과 글자 크기를 확정한다.
3. 실제 한글 타이핑 조작과 메시지 진행 규칙을 구현한다.
4. 확정된 배치와 크기를 기준으로 현재 사각형 기반 외부 SVG에 부장 행동 및 도윤 입력 상태 포즈를 수정·추가한다.
5. 준비된 외부 SVG 포즈를 사용해 직접 경고 UI를 부장 행동 기반의 간접 예고로 교체한다.
6. 실제 타이핑과 부장 행동을 함께 플레이테스트해 메시지 길이, 제한 시간, 반응 시간, 감시·훼이크 비율과 결과 기준을 조정한다.
7. 배경·캐릭터·메신저 UI의 색감과 재질, 전송 성공·발각·답장 도착 연출을 최종 정리한다.

앞 작업의 결과가 뒤 작업의 기준이 되므로 이 순서를 유지한다. 화면 배치와 표시 크기는 외부 SVG 포즈의 좌표와 표시 배율을 결정하고, 실제 타이핑 상태는 부장 감시의 발각 판정을 결정한다. 부장 행동과 경고 UI는 행동 포즈와 실제 입력 상태가 모두 준비된 뒤 구현하며, 최종 제한 시간과 난이도 등급은 두 기능을 통합한 플레이테스트 전에는 확정하지 않는다.

## 공통 작업 원칙

- PC 데스크톱 브라우저만 지원한다.
- 각 수정은 DAY 2 독립 Lab에서 먼저 검증한 뒤 본편 통합을 확인한다.
- `SecretChatMinigame.start({ onComplete, affection })` 호출 형태와 완료 결과의 `grade`, `workDelta`, `affectionDelta`, `sent`, `warnings`, `elapsed` 필드는 유지한다.
- 호감도별 하린 답장과 DAY 2 스토리 진행은 수정 대상에 명시하지 않는 한 유지한다.
- 강한 모션은 부장의 행동 변화, 발각, 전송 성공에만 사용한다.
- 직접적인 위험 안내를 다시 추가하지 않는다. 행동 단서는 명확해야 하지만 `주의`, `위험`, `곧 뒤돌아봄`처럼 정답을 말하면 안 된다.
- 이미지 에셋을 변경할 때는 저장소 아트 파이프라인과 승인본 불변 규칙을 따른다.
