# Runtime static assets

브라우저가 직접 읽는 공용 정적 파일 폴더입니다.

- `audio/`: BGM과 UI 효과음
- `fonts/`: 웹폰트
- `backgrounds/`, `characters/`, `CG/`, `image/`: 매니페스트 도입 전부터 남아 있는 레거시 런타임 이미지

생성 이미지의 승인본과 생성 이력은 저장소 루트 `assets/art/`에서 관리합니다. DAY 4 퇴근 미니게임 이미지는 `assets/art/minigames/day4-office-escape/`에 있으며 이 폴더에 추가하지 않습니다.
